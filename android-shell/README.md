# WordCraft Android Shell

Capacitor WebView shell for the WordCraft web (WASM) build.

## Setup

```bash
cd android-shell
npm install
npx cap add android
```

## Build

`android/` is generated by Capacitor and is not committed. The web build is
copied to `www/` by the CI workflow (`trunk build --release` writes to
`<repo>/dist/web`, see `apps/wordcraft-web/Trunk.toml`). To do it locally:

```bash
cd apps/wordcraft-web
trunk build --release
cd ../../android-shell
mkdir -p www && cp -r ../dist/web/. www/
npx cap add android          # generates android/ (skipped if it exists)
cp android-manifest.xml android/app/src/main/AndroidManifest.xml
npx cap sync android
```

## DeX

`android-manifest.xml` (copied over the generated
`android/app/src/main/AndroidManifest.xml` by CI and by the steps above)
includes:
- `android:resizeableActivity="true"`
- `android:configChanges="orientation|screenSize|smallestScreenSize|screenLayout|keyboard|keyboardHidden|density|uiMode"`
- `android:windowSoftInputMode="adjustResize"`

These prevent the app from restarting on window resize in DeX.

## File bridge

Saving uses the browser download fallback (blob → anchor). On Android WebView,
intercept `<a download>` clicks and save via `@capacitor/filesystem` + `@capacitor/share`.
Implementation: the generated `android/.../MainActivity.kt` (default Capacitor
`BridgeActivity`; both plugins auto-register in Capacitor 6).
